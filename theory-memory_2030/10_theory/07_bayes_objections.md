# M07 — ベイズ、SSA/SIA、測度否定

主出典[013](../30_articles/013.md)〜[018](../30_articles/018.md),[027](../30_articles/027.md),[041](../30_articles/041.md),[060](../30_articles/060.md),[066](../30_articles/066.md),[067](../30_articles/067.md),[072](../30_articles/072.md)。

`Posterior odds(b:a)=Prior odds(b:a)×P(O|b)/P(O|a)`。Oを「現代起点の人間系列」等に固定する。生存/人間一般/非sim/現在の瞬間に途中で替えない。`P(O|W)=M(O|W)/M(all|W)`は測度モデルを受け入れた内部定義。

現行例: p0=2e-6、b側を.5まで上げられるならΛ≈2.5e5。これはbの事前を与えず、bの実現可能性を確認した値でもない。ΛはPの目標値/参照/系列免除に依存する。014の1e6〜1e30、066/067の約8.7e9は旧仮定の値。

SSA=観測者を自己位置の候補にする。SSSA=観測者瞬間、SSSSA=瞬間を認知的サイズでも重み付け、という017の先行研究紹介。著者式は系列全体の量＋内部時点免除なので、SSSAの名称だけで同一視しない。SIA=主体が多い世界への存在ボーナスを加えると、SSAの出生順位ペナルティが相殺されうる。018は不採用を論じ、060は採れば未来出生の第二部は成立しないと認める。世界内の比率計算と世界間の選択原理は別。

測度否定の4型:

|型|Aの応答|残る論点|
|---|---|---|
|外在抽選などない|自己位置の分布に選択者は不要|分布/橋渡しそのものを拒否する立場には尤度比較だけでは届かない|
|稀な目が出ただけ|無矛盾だが同じ測度なら尤度が低い|低事前のbより優勢もありうる。説明不要と宣言できる|
|質問できる人だけ数える|報告条件と意識資格を混同|観測プロトコルを明記した選択効果の扱いはなお必要|
|誰かは人になる|三人称的存在と私の自己位置は別|同一性/指標性の理論選択に依存|

トークンとタイプ: 一枚ごとの宝くじが稀なのは当然、しかし999999匹動物対1人人間の粗いタイプが稀なのは別。どの粗視化が事前に正当かを後付けせず定める。

日常較正: 巨大人口国の住民/稀少病でない/億万長者や五輪選手でない、等を個体一様に近い測度の足場とする。ただし067自身が、種と歴史への参照拡張、個体vs個体年、未来から現在への推論は較正範囲外と認める。070のn較正の限界は[M01](01_measure.md)。

重複証拠を避ける: 人間である/BBでない/未来人工でない/下層simでない/長寿入口は非独立。非simは観測から確定しない。長寿→倫理推論を倫理→長寿の独立支持として掛け戻さない。複数の同じ結論の記事も独立観測でない。

DOOM内訳: 人間が終わるだけで後続意識が大量にあれば分母は増える(015/016)。全意識が終わる世界と区別。非倫理ASI→必ず意識大量生成という仮定を一律に課さない。
