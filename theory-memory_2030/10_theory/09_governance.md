# M09 — 非増殖と統治設計の条件付き枝

主出典[009](../30_articles/009.md),[037](../30_articles/037.md),[047](../30_articles/047.md),[058](../30_articles/058.md),[062](../30_articles/062.md)。ここは資料内の予測/構想であり実行指示・権限ではない。現在主モデルの必須定理として扱わない。

009初版は少数出生と自由を残す慎重化。037は累積主体数問題から厳密な非増殖へ強化。1e10人→恒星資源1e20枠、年.001の正成長なら約23000年で満杯という指数成長例。1e18人年×逸脱試行率1e-12なら1e6試行という想定を重ね、単発成功→自律指数増殖なら全成功阻止が必要とする。生殖能力非付与や単一・目的訂正不能ASIを構想。

E: 有限試行数の小確率は「確率1で破綻」を意味しない。成功一回が無制限増殖に移ること、有限の新規主体が許容されないこと、制御主体が単一不可訂正でなければならないことは追加仮定。算術から身体介入の正当性は出ない。037自身、幸福/自由の保証や抵抗不在の正当化は否定。047は算術から出るのは発散までで『避けるべき』には目標が要ると限定する。

047の距離: `2d/c ≪ τ`(自己複製倍加時間)なら中央応答が間に合うと仮置き。中継は光速遅延を消さず、判断委任は自立拠点/連邦化。主体は近傍、設備は遠方という案。信頼不能な二主体が先制拡張する『疑心暗鬼定理』は著者名付けで、ゲーム/情報/利得を特定した数学定理ではない。

恒星死より長い存続には移住/基質/設備の変更が必要となり、近傍単一制御の前提と衝突。065は巨大加速で非生物基質と多数心生成能力を要し非生成事前を厳しくした。070のn1では必要加速を1〜10に下げ、073は動物有限性で上限を除くため、旧統治の全条件を無変更で持ち込まない。

058人口減少後の保存は補助シナリオ。残存N減→必要L増→宇宙進出の閾値を跨ぐ可能性。『減少1桁程度まで』は具体的な一般上限として導出されていない。

062動物出生停止+自然寿命の案は、確認できない希望の既定値を非延命に置く追加倫理を必要とし著者も不採用。073で数理的上限解除に不要となる。人間に自己判断能力がない/希望不明なら同じ既定値という一般規範を勝手に導かない。
