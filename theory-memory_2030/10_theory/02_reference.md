# M02 — 参照クラスと観測の範囲

主出典[005](../30_articles/005.md),[027](../30_articles/027.md),[039](../30_articles/039.md),[046](../30_articles/046.md),[067](../30_articles/067.md),[072](../30_articles/072.md),[073](../30_articles/073.md)。

A: 説明対象は「私がこの人間系列であること」。全く同じ記憶を持つ人や、この質問を発話できる主体に最初から限定すると説明対象を分母定義に埋め込む。虫/マウスが質問しないことは、それらに経験がないことを意味しない。前言語期の私も経験主体に含む。

`E=人間として質問する`なら`P(E|動物)≈0`から`P(動物)=0`は導けない。報告者を見た後の確率と、報告能力を得た自己位置の確率を分離。ただしこの区別だけで著者の測度が唯一正しいとは決まらない。

参照の推移: 001虫を含む巨大数→036/069神経相同性の強い過去哺乳類→046/065/072魚類まで。昆虫意識は未確定で既定の数表から外すが、無意識と断定していない。脊椎動物基準は魚だけで全群の精密な人口/意識を網羅したものではなく、魚の桁が支配する近似。039長鼻目だけの比較は人間に有利な頑健性実験で正式分母の縮小ではない。

過去を含めるため、現存個体数/累積個体数/累積個体年を区別。累積は現在密度×補正×系統年齢という強い近似、実測歴史台帳ではない。人類は出生1.17e11から主体閾値未到達を除き7e10、これに70年を掛け4.9e12個体年と置く。E: 積分型なら幼児にも短い薄い経験があり、成人寿命一律適用も粗い。閾値除外と現在積分の整合を再検討対象に残す。

未来の新規人間/人工意識も同じ参照に入れる。既存人間由来系列の延長と、新たな主体の大量生成は分子への寄与先が違う。シミュレーションでも意識があれば原理的には参加、ゲームや計算だけで無意識なら参加しない。

空間の境界: 現行数表は地球一生物圏。宇宙全体の同類意識/異星文明/上位simは未積算。独立100万生物圏を同様に足せば競合は概ね6桁増えるが、各文明で人類型系列も増えるなら単純分母だけ追加とは異なる。比較する観測タイプを固定する。

BB(ボルツマン脳): 001/012は短い非連続系列が低測度として処理できる可能性を挙げる。しかし個数/時空体積が無限なら有限の短さだけでは正規化できず、後期の地球有限モデルで解決された問題として扱わない。

現代起点系列/現代の瞬間/人類一般/非simの実在は別の観測。見かけだけから基底現実や非人工を確定できない(011/013)。
