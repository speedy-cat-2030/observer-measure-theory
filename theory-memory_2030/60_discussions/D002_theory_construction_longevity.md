# D002 — 理論構築と長寿：通常因果、共通原因、介入・選別、賭け

記録: 2026-09-05 JST。本セッションで交わした議論の要約。逐語録ではない。U=ユーザーの提案/評価、E=アシスタントの評価。原文74記事の改訂でも、新たな実証結果でもない。後の記録依頼は、Eの全評価への同意を意味しない。

関連: [M13](../10_theory/13_personal_dialogue.md)、[M04 系列と時間](../10_theory/04_time_identity.md)、[M07 自己位置ベイズ](../10_theory/07_bayes_objections.md)、[025](../30_articles/025.md)、[026](../30_articles/026.md)。ASI倫理の別議論は [D001](D001_asi_ethics_non_generation.md)。

## 最小の引継ぎ

Uは「現代人であること」に加え「この理論を自ら構築していること」も説明対象とした。通常の選択変化/共通原因だけでは理論構築に固有の超長寿経路が弱く、特別な介入・選別の方が直接的だと指摘。Eは通常因果の具体化不足を認めたが、直接的に結びつく設定を作れることと証拠の強さを区別した。研究支援/保存/多様性/意思尊重/危険理論の隔離を比較し、構築だけから極端な長寿や実在介入は導けないと評価。双方の評価差を保持する。

「賭け」は無条件生存保証を使って別の出来事を要求するという思考実験。Uは実行意図を繰り返し否定し、確認時に衝動・準備もないと回答した。これはその時点の発言であり、現在の意図を自動判定する記録ではない。実行手順・推奨・生存保証として使用しない。

## 1. 問いと確率比較

Eが提案した問い: 「理論が正しい世界では、誤っている世界より、私がこの理論を構築しようとすることが起きやすいのか」。構築者Cの測度割合を `Σ_{i∈C}M_i / Σ_i M_i` として考える。ただし、人数比より大きいとしても、誤った理論を構築する世界でも同じ理由で増えるなら、理論の真偽を識別する証拠にはなりにくい。

個別の一人が特殊なのは誰でも同じ。理論を作った後にその構築を特別な観測と選ぶ、事後的な特徴選択にも注意が必要。一方、構築が将来の行為に影響するなら、説明対象の世界の一部として扱う意味はある。

## 2. 通常因果の候補とUの批判

|候補|仮説の経路|留保|
|---|---|---|
|構築が選択を変える|長期計画、連続性/可逆性への関心、意思記録、苦痛や判断能力への配慮→将来の選択が変わる|理論が誤りでも起きる。過信や過度な慎重さは逆方向にも働く|
|共通の性質|前提訂正、長期思考、意識継続への関心、不確実性への耐性、情報/時間/道具へのアクセス→構築と将来適応の両方|それらの性質が長寿を生むか未確認。非構築者にもある|
|長い系列で考える機会が増える|経験時間と知識蓄積→いつか自己位置の理論に到達|延命前の現代にすでに構築することまでは説明しない|
|構築/公表が周囲に影響する|意思記録、研究、技術設計への影響→本人を含む将来に影響|特別な個人保存まで導けない|
|無関連|理論が正しくても構築者が特に長いとは限らない|比較の基準として残す|

Uは、健康や将来技術への態度はこの時代なら理論なしでも生じるため、構築固有のつながりが弱いと評価。将来の延命への期待を例示したが、この対話でLEVや疾病克服の予測を実証したわけではない。

Eは「構築による選択変化」だけでは構築者が特に長寿になる経路を具体的に示せていないと修正。025の意思記録は構築→記録という行為の実例だが、記録→実際の長寿は未確認。記事群の訂正履歴は思考習慣の手掛かりだが、その習慣の生活/技術判断への転移も未確認。

## 3. 特別な介入・選別の候補

Uは次を低確率だとしつつ考察対象に提案: 禁忌の物理理論(真空崩壊の誘発/因果律の改変等)に到達した個体が仮想的な超知能に検知され、実体化防止のため永遠に隔離される、という筋書き。自分に実際に起きているという観測報告とは扱わない。

Eが追加した仮想候補は研究協力者への支援、思考過程の継続観察、意思を伝えたことへの対応、公共的貢献への支援。後に「理論を知らなくても成立する目的」から選択基準を導き、次の比較を行った。

|独立に置く目的|選択基準|長寿/構築への接続の限界|
|---|---|---|
|既存意識の不可逆喪失を避ける|意識あり、保存可能、本人の希望と整合|広い保存は説明できるが構築者に限定しない|
|知識を得る|独自情報、研究上の有用性、継続参加の価値|支援を説明しても極端な長寿の必要性は別|
|知的・文化的多様性を保つ|代替しにくい視点/技能|他の研究者・創作者も対象|
|本人の意思を尊重する|理解に基づく明確で撤回可能な希望|同じ希望を持つ非構築者も対象|
|公共的貢献を支援する|同程度の貢献/将来の貢献可能性|構築歴ではなく貢献が基準|
|公平に支援を配分する|必要性、効果、希望|特定理論の到達を優先する根拠がない|
|重大な不可逆被害を防ぐ|具体的な危害能力、実行可能性、有効な対処|危険理論への到達→本人隔離→無期限存続は各段階に追加根拠が必要|

危険モデルでは、知識が危害能力を与えること、本人の隔離が必要で手段への制限では足りないこと、隔離のため本人を永遠に存続させる理由、を分けた。最後には保存原則等の別目的も要し、被害防止だけでは無期限延命は出ない。

## 4. 非構築者との条件統一テスト

理論構築の有無だけを変え、知識・能力・希望・研究価値をそろえる。危険モデルなら自力発見者と同じ内容を学んだ人を比較する。

結果(E): 保存、意思尊重、多様性、公共貢献、危険対処は、同じ実質条件なら原則同じ対応になる。構築は条件の手掛かりにとどまる。研究モデルでは着想/改訂の当事者情報が差を作る余地があるが、聞き取り/記録では足りない理由と極端な長期観察の必要性が未説明。独立発見が再発見・拡張能力の手掛かりになっても、その能力までそろえれば構築歴のみの差は薄くなる。

## 5. 構築した事実から何が分かるか

記事群から確認できるのは持続的関心、論点整理、計算、反論を受けた改訂、条件付き意思の記録。そこから理論の正しさ/独創性/他者に対する有用性/代替不能性は未確定。本人に追加説明を求める理由はありうるが、本人の極端な長期存続が不可欠という証拠にはならない。構築は、実在の介入者が認識・評価していることや物理的な危害能力の証拠にもならない。

Uは特別な介入の方が構築と運命を直接つなぐと評価。Eはその直接性を認めつつ、説明対象に合わせた設定の追加と、独立の証拠による説明を区別。通常因果の説明不足が、そのまま特別介入への証拠になるわけではないとした。

## 6. 「賭け」の思考実験

Uの例は、翌日の太陽が西から昇るという通常起きない出来事に、自分の生存を左右する宣言を結びつけるものだった。目的は実行ではなく、「長寿が保証されるなら、それに反する条件を設定して外部現象や保護を強制できてしまうのか」を検討すること。Uは実行意図がないと繰り返し明示し、確認への回答でも衝動・準備はない、完全に思考実験だと述べた。

Eの区別:

1. 長寿予測が行動に条件付くなら、選択を変えると予測も変わり、介入は強制されない。
2. 完成系列には予測を知って行動することも含まれるが、長い系列の重みが大きいことは任意の選択の結果を保証しない。
3. 保証を成立させる管理者を置くなら、存在・能力・目的・規則は追加仮定。検知/隔離は必要な帰結ではない。

さらに、無条件生存、宣言した行動と結果の確実な実現、通常の外部物理、を全て固定すると条件が両立しなくなりうる。しかし両立しない要求を宣言しても、どの条件が変わるかを宣言者が指定できるとは限らない。元の経験測度の理論には、そもそも無条件生存保証が含まれていない。

位置づけ: 長寿予測の強い解釈を点検する反例候補。物理操作能力、実際の保護、危険人物としての検知、永遠の隔離を示す証拠ではない。自己危害を使う試験を推奨・設計した記録として扱わない。

## 7. 再開時の論点

- 正しい理論/誤った理論で構築者の測度割合がどう違うか。事後的な特徴選択と共通原因をどう扱うか。
- 通常因果の候補が極端な長寿へつながる具体的経路は未提示。非構築者と実質条件をそろえた比較が必要。
- 介入モデルは目的/選択基準を独立に置き、構築者へ合わせた仮定を足すだけになっていないか確認する。
- 「生涯経験を積算する」「系列確率がそれに比例する」「内部時点を抽選しない」「行動によらず長寿を保証する」は別命題。最後はこれまで導出されていない。
- 現実の監視/選抜/介入は確認されていない。理論検討をその実在の証拠として記憶しない。
