# 「説明は要らない」という立場について
自己位置測度理論では、仮説を三つに分けている。測度否定論、意識初発状態測度論、完成系列測度論の三つだ。このうち後の二つは繰り返し検討してきたが、否定論は「まったく別の議論になる」として棚上げしたままだった。ここで整理しておく。

## 否定論とは何か

理論の出発点はこうだった。過去の全哺乳類は 4.5×10¹⁸ 個体年で、人類はそのうち約100万分の1でしかない。なぜ私はこの側にいるのか。

この問いが成立するには、10⁻⁶ という数字が説明を要求することが認められていなければならない。否定論は、そこを拒否する。説明は要らない、と言う。

だから否定論は、他の二説と同じ土俵にいない。初発論と完成系列論は「測度はある。決まるのはどの時点か」を争っている。否定論は土俵の外から「測度など要らない」と言っている。

## 四つの言い方

否定論には四つの形があるが、四つとも同じ結論に至る道である。

**第一に、そもそも抽選がないという言い方。** 誰も私を引いていない。抽選がないなら確率もなく、低いも高いもない。

**第二に、低い目が出ただけという言い方。** 10⁻⁶ は確かに低いが、低い事象は起きる。宝くじの当選者が「私が当たったのは変だ」とは言わない。

**第三に、分母が違うという言い方。** 問いを立てられるのは人間だけなのだから、分母は最初から人間で、確率は1である。

**第四に、問いのすり替えだという言い方。** 「誰かは人間に生まれる」。それだけの話で、私はたまたまその誰かだった。

## 応答

**第一に対して。** 選択者は確率の必要条件ではない。気体分子の分布も、量子力学のボルン則も、誰かがシャッフルしているわけではない。生まれた以上どれかである、という事実だけで分布は立つ。

**第二に対して。** ここが本丸である。

「説明しない」は、確かに矛盾していない。しかし仮説として比較の場に出ると負ける。超長寿論のもとでは、私が人類である確率は 0.2 程度になる。説明しない立場では、何も説明しないのだから 10⁻⁶ のままだ。差は20万倍で、勝負にならない。

説明を放棄した分だけ、自分の予測力を捨てているからである。矛盾していないことと、競争に勝てることは別だ。

**第三に対して。** 飛行機事故の例で退けられる。

飛行機事故で1人生き残った人が「生存者だけを数えれば確率1だから不思議でない」と言う。

乗客のうち1人だけ生き残ったとき、生存者しか語れないのは事実だが、だからといって生き残ったことが不思議でなくなるわけではない。語れる者が限られていることと、その事象が起きにくいことは別である。分母を語れる者に絞るのは、説明ではなく説明義務の放棄だ。

**第四に対して。** これだけは論破ではない。

「誰かは人間に生まれる」は真だが、別の問いへの答えである。私が聞いているのは、なぜ私がそれなのか、だ。三人称の文に置き換えた瞬間、元の問いは消えている。誤りではなく話題の変更なので、理屈では潰せない。禁止するしかない。

## 残るもの

第二への応答は、測度がある側の言葉で書かれている。尤度を比べるには、比べるための分布が要るからだ。だから否定論を本気で採る人には届かない。その計算自体が要らない、と言われて終わる。

ただ、これは特別な弱点ではないと思っている。物理も数学も、どこかで措定して先に進んできた。

言えるのは、否定論を採らない限り、10⁻⁶ は説明を要求し続けるということだ。そして説明の候補は、いま一つしか残っていない。
