# 意識初発状態測度論でほぼ固まった
自己位置測度について、現在は完成系列測度論よりも、意識初発状態測度論を強く支持している。

ただし、ここでいう「意識初発」は、最初の感覚が発生した瞬間ではない。

乳児期には、小動物に近い薄い現象意識が存在する。その後、記憶、自己モデル、言語、時間的統合などが発達し、ある臨界点を越えることで、現在まで続く「現在型主体」が成立すると考える。

自己位置測度は、この主体形成の相転移に付随するのではないか。

このモデルでは、小動物や乳児初期の薄い現象主体の測度は極めて小さい。一方、現在型主体が成立すると測度が急増し、その後は飽和する。

そのため、人間の意識内容がネズミの一億倍豊かである必要はない。現在型主体が成立しているかどうかによって、自己位置測度に一億倍級の差が生じてもよい。

また、閾値を越えた後は、多くの人間がほぼ同じ測度を持つ。成人後のIQ、才能、寿命、総経験量は、すでに成立した主体が経験する内容であり、主体の割り当てを決め直すものではない。

人間同士がほぼ一人一票なら、なぜこの時代、この国、この個人なのかについては、人数に比例したランダムな自己位置でも特に不自然ではない。近現代は現在型主体の成立数が多く、未来も長寿化と出生抑制、または文明的破局によって、新規主体数が無制限に増えない可能性がある。

完成系列測度論では、未来の寿命や経験量まで、主体形成時の自己位置測度に反映される。しかし、一度成立した主体が連続して同じ人生を進むなら、なぜ後続経験を初期の割り当てへ加算するのかは不明である。

現時点での私の主観的信用度は、二説に限定すれば、

-

意識初発状態測度論：85％

-

完成系列測度論：15％

程度である。

まだ、現在型主体を成立させる臨界構造や、なぜ相転移によって測度が急増するのかは分からない。

それでも、**主体が形成されるときに自己位置測度が成立し、その後は同じ主体が連続して経験を続ける**という意識初発状態測度論が、現在は最も自然に見える。
