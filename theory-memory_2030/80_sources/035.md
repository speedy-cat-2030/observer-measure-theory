# 現前性
以前、私は自己位置測度について、意識主体が成立した最初の状態で測度が決まる「意識初発測度論」を有力だと考えていた。しかし、ブロック宇宙、相対論的な固有時、量子論の関係的時間を踏まえると、現在は「完成系列測度論」の方が自然だと考えている。

## 主体は一瞬ではなく系列全体である

ブロック宇宙では、過去・現在・未来の出来事は、四次元時空内の異なる位置として存在する。

固有時τにおける意識状態をC(τ)とすれば、主体の人生全体は、

S = { C(τ) }

という一つの意識系列Sとして表せる。

この見方では、私とは誕生時の一断面ではなく、記憶、自己モデル、判断、未来表象などを含む、誕生から死までの完成した系列全体である。

完成系列測度論では、どの主体系列が私として対応づけられるかは、系列全体の何らかの性質によって決まる。

模式的には、

P(Si) ∝ M(Si)

と表せる。

これは、主体系列Siが私として対応づけられる確率P(Si)が、その完成系列全体の性質M(Si)に関係するという意味である。

M(Si)の具体的な内容は未確定だが、記憶の連続性、通時的自己モデル、未来表象、情報統合、再帰的自己認識などが候補になる。

## なぜ私は「今」を経験しているのか

完成系列全体が私だとしても、別の問題が残る。

なぜ私は人生全体を同時に経験するのではなく、現にこの時点を「今」として経験しているのか。

ここで仮定するのが、意識に固有の「現前性」である。

現前性を、メタ時間の中を動く物体として考える必要はない。むしろ、

C(τ)が現前する ↓ 因果的に後続するC(τ + Δτ)へ現前性が継承される

という基本的な心理物理法則として考える。

相対論では、宇宙全体に共通する絶対的現在は存在しないが、各主体の世界線には固有時があり、その上の出来事には因果的順序がある。そのため、現前性は宇宙全体の時間面ではなく、各主体の固有時に沿って継承されると考えられる。

また、Page–Wootters型の関係的時間では、宇宙全体の量子状態が静的でも、内部時計との相関によって系列的な変化を記述できる。これは、外部のメタ時間を置かずに、C(τ)からC(τ + Δτ)への推移を表現する足場になる。

量子デコヒーレンスと記録形成は、意識系列が一貫した古典的履歴を持ち、過去方向の記憶だけを形成する理由にも関係し得る。

ただし、相対論や量子力学に「現前性」という変数が存在するわけではない。既存物理が与えるのは、固有時、因果順序、関係的時間、履歴、記録形成までである。現前性そのものは、それらに従って意識系列上を継承される追加の心理物理的性質として仮定される。

## なぜ現在の生物だけを数えないのか

自己位置の候補を、現在存在する生物だけに限定する理由もない。

私が小動物ではなく人間であることを説明するなら、比較対象には現在の哺乳類だけでなく、過去や未来を含む、すべての意識主体系列を入れる方が自然である。

ブロック宇宙では、過去の哺乳類も現在の哺乳類も、四次元時空内の異なる場所に存在する系列である。

逆に現在の主体だけを測度対象にするなら、なぜ現在という時点だけを特権化するのかという説明が必要になる。しかも相対性理論には、宇宙全体に共通する絶対的現在がない。

したがって自己位置測度は、ある瞬間の生物集合ではなく、時間を横断した完成意識系列全体に対して定義する方が自然である。

## 意識初発測度論との比較

意識初発測度論では、最初の意識状態C(τ0)だけが自己位置測度を決め、その後の人生全体は測度に影響しないと考える。

しかしブロック宇宙では、C(τ0)もその後の状態も、一つの完成系列Sの構成部分として存在する。

そのため初発論には、

完成系列全体が存在するにもかかわらず、始端の一断面だけを測度決定点として特別扱いする

という追加規則が必要になる。

さらに、乳児や胎児の意識発達は連続的であり、どの瞬間を初発とするかも明確ではない。

完成系列論では、初発は測度決定点ではない。現前性の継承が始まる、系列上の端点にすぎない。

## 測度はどの層に働くのか――系列間比較と系列内継承の区別

ここまでの議論には、明示しておくべき前提がある。それは、完成系列測度M(S)が、二つのまったく異なる層のどちらに働くのか、という区別である。

第一の層は、系列間比較である。異なる系列同士、あるいは分岐点において実現しうる複数の候補系列同士を比較し、どちらがより大きな測度を持つかを問う。人間の系列と虫の系列の比較、ボルツマン脳という系列と通常の人間系列の比較、あるいは現在の分岐点から先、70年で終わる系列に進むか800年続く系列に進むかという比較は、すべてこの層に属する。P(Si) ∝ M(Si) が扱っているのは、この系列間比較である。

第二の層は、一つの系列が確定した後、その系列内部のどの時点τが「今」として経験されているか、という系列内時点の問題である。これは測度比較の対象ではない。現前性は、系列の中をC(τ)からC(τ + Δτ)へ、因果継続的に歩むだけであり、時点ごとに測度を割り当てて「なぜこの時点が今なのか」を問うことはできない。今この時点にいるのは、単に自分の因果的な糸がそこにあるからであって、それ以上の説明を要求される問いではない。

この区別を明示するのは、両者を混同すると、理論全体の一貫性が崩れるからである。

なお、以下でO1〜O5と呼ぶのは、12本目「ASIは人類を滅ぼすのか：ベイズ推定と人間原理①」で定義した観測事実の内訳である。「私は現代の生物的人間として存在している」という観測事実Oを、O1：虫ではなく人間である、O2：ボルツマン脳ではなく連続した人生を持つ、O3：AIと長寿技術の入口にいる現代人である、O4：超未来の人工意識・仮想人格ではない、O5：さらに内側の祖先シミュレーション存在ではない、の五つに分解したものである。

たとえば「私は現代の生物的人間であり、超未来のAI意識ではない」という観測は、系列間比較にあたる。これは、異なる系列(現代人という系列と、未来AI意識という系列)のどちらに自己位置したかを問うており、第一の層の問題である。

一方、「仮に自分の系列が10⁸年続くとして、なぜその系列の最初の数十年、しかも老化制御が確立する以前のこの時点にいるのか」という問いは、系列内時点の問題であり、第二の層に属する。この理論の立場では、後者は測度比較の対象ではなく、そもそも問いとして成立しない。系列が(第一の層で)選ばれた後は、時点は抽選されず、ただ因果的に歩まれるだけだからである。

したがって、これ以降の記事でO1〜O5のような観測事実を測度比較に用いる際は、それが系列間の比較であることを前提とする。系列が確定した内部でどの時点にいるかについては、この理論の枠組みでは測度による説明を要求しない。

## 現時点での評価

以上を踏まえた私の主観的信用度は、二説に限定すれば次の通りである。

完成系列測度論：85％ 意識初発測度論：15％

これは実験データから算出した確率ではなく、ブロック宇宙との整合性、仮定の少なさ、時間横断的な参照クラス、人間と小動物の違いに対する説明力を総合した評価である。

現時点で最も一貫しているのは、次の三層構造だと考えている。

ブロック宇宙：人生全体を四次元的系列として成立させる。 完成系列測度：どの意識系列が私かを規定する。 現前性継承則：その系列のどの断面が今として経験されるかを担う。

要約すると、

私とは完成した意識系列であり、自己位置測度はその系列全体に関係する。 その系列内部では、一人称的現前性が固有時と因果順序に従って継承される。

という仮説である。

これは確立した物理理論ではない。しかし、ブロック宇宙、自己位置、現在経験を役割の異なる問題として整理し、最小限の追加仮定で接続する理論枠組みとしては、意識初発測度論より自然に思える。
