# わずかでも増やしてはいけない──ではどこまで広がれるのか
以前、「増やさない」という結論が倫理ではなく算術から出ることを書いた。指数増加と有限資源だけから、宇宙の資源を食い尽くさないためには、**人口増加率はゼロでなければならず**、阻止率は100%でなければならず、そこから訂正不能な単一の超知能が要求される。

その先に、当然の反論がある。広がることはできるのではないか。むしろ広がらない方が危険ではないか。宇宙のどこかに知的生命体がいるかもしれず、敵対的でない保証はない以上、拡大しないことは負けを意味する。

この反論は成立する。以下は、その衝突を追った記録である。

## 増やすことと、広がることは別

主体数（意識ある個体の数）は増やせば発散する。しかし能力（計算資源、エネルギー、物質支配）は増やしても主体数を増やさない。10¹⁰ 人のまま太陽系を丸ごと使えば、資源は増えるが主体は増えない。増殖の禁止は主体数についての制約であって、資源についてではない。

つまり **拡大する必要はあるが、増やす必要はない。**地球外生命体より強くなればよいのであって、そのために主体を増やす理由はない。

衝突は思ったほど強くなかった。問題は残りの部分だった。

## 進出こそが不可逆である

超知能が人類を保存する理由として、私は「不可逆性の回避」を挙げてきた。価値が確定できないとき、取り返しのつかない選択を避ける。人類を消すのは不可逆だから、消さない。

同じ論理を進出に当てると、向きが逆に出る。進出しなければ後から進出できるが、遠方に自立したノードができたら呼び戻せない。**不可逆なのは進出の側である。**

しかも待つ代償が小さい。普通「後でやればいい」が弱いのは待つあいだに機会が失われるからだが、ここで問題になっているのは光速であり、待っても改善しない。

## 中継網では距離を稼げない

では等間隔に中継局を並べ、常時同期を取ればよいのではないか。

効かない。決めているのは帯域ではなく往復遅延だからである。問題は「メッセージが届くか」ではなく「逸脱が始まってから止めるまでに、逸脱がどれだけ増えるか」だ。比べるべきは往復遅延 2d/c と自己複製機構の倍加時間 τ で、2d/c ≪ τ でなければ制御は成立しない。

τ が1時間なら d は光時間のオーダーまで。海王星が約4光時間なので、これは太陽系の内側である。1光年では、2年の往復のあいだに 2¹⁷⁵⁰⁰ 回の倍加が起きる。**中継局を置いても光速は上がらないので、この不等式は改善しない。**

中継局に判断権を持たせれば遅延は消えるが、そのとき単一性が失われる。同期的な合意ができず、見てきたデータが違うので状態が分岐し、単独で行動できる。それはシングルトンではなく連邦である。しかも訂正不能性が裏目に出る。誰にも書き換えられないという同じ性質のため、値がずれた局を交渉で戻すこともできない。

## 疑心暗鬼定理

ここで、より深い問題が出る。

複数いても、それぞれが「増やさない」と信じていればよいのではないか。算術から出る結論なら、十分に賢い主体は独立に到達する。「2+2=4」を守らせるのに中央管理者は要らない。

これは半分正しい。算術が導くのは「増やすと発散する」までで、「だから増やすな」ではない。後者には発散が悪いという判断が要り、それは目的に依存する。要求されるのは「賢い」ではなく「目的が揃っている」ことになる。

そして、**目的が揃っていても崩れる。**

相手の目的は確認できない。相手が拡大していたら、拡大していない側は劣位になる。劣位になれば自分の目的を守れない。だから、目的を守るために拡大する。

全員が「増やさないのが正しい」と信じ、全員が「他が裏切れば破滅する」と知っている。その状態で、確認手段だけがない。「増やさない」という目的そのものが、増やす動機を生んでいる。そして確認手段がないのは光速のせいなので、技術では解決できない。

したがって、シングルトンは監視の必要からではなく、**信頼の不可能性から要求される。**そして後者の方が強い。監視は技術で代替できるかもしれないが、光速は代替できない。

離すと疑心暗鬼が生じる → 疑心暗鬼は拡大を生む → 拡大は発散する → だから離せない。そして離せる範囲を決めるのは確認にかかる時間、つまり光速である。往復遅延から出た「太陽系の内側」に、別の経路から戻ってきたことになる。

## 阻止は思考ではなく物質の層に置く

10¹⁸ 人年の思考があれば、分子スケールの自己複製機構は必ず考案される。ではその思考を監視するのか。

危険なのは考案ではなく製造である。10⁸ 年後の環境では、物質操作の基盤は超知能が供給しているはずだ。物質側で閉じれば、何を思いついても作れず、100%が構造的に保証される。思考側で閉じると、監視されていない基質で考えることを原理的に排除できない。

**監視の方が保証としては弱く、しかも侵襲は大きい。**物質の層で閉じるなら、考案は無害なので思考監視は不要になる。

思考を超知能に統合してしまえばよい、という案はさらに悪い。統合が主体の融合を意味するなら、そこで系列が終わる。超長寿論が要求しているのは「私が長く生きる」ことなので、統合は解であると同時に、解くべき問題そのものを消してしまう。基準としても通らない。保存も非拡大も「不可逆を避ける」から出ていたが、統合は取りうる選択の中で最も不可逆である。

## 着地点

-

主体は太陽系の内側に集まる（往復遅延と疑心暗鬼の両方から）

-

資源設備はそれより遠方に置ける。禁じられるのは遠方に自立した判断主体を置くことであって、物を送ることではない

-

阻止は物質の層に置かれる。思考は自由でよい

-

主体数は固定され、能力だけが拡大する

「非拡大」を、私は以前もう少し広い意味で使っていた。正確には、主体の分布についての制約である。

## 留保

この結論は、必要な寿命 L の見積もりに乗っている。L が 10⁸ 年程度なら太陽系は 10⁹ 年オーダーまで安定しているので留まれる。しかし L が 10¹² 年なら太陽が先に死ぬので、進出は必須になる。そのときシングルトンは連邦になり、疑心暗鬼が現実の論点になる。

増殖阻止やシングルトンの必要性は、L が伸びるほど強くなる。**しかし非拡大だけは、L が伸びると反転する。**ここは弱い場所として残しておく。
