# なぜ私たちは何京匹もいる「虫」ではなく、たった80億人しかいない「人間」を引けたのか #2 反論
[https://note.com/speedy_cat_2030/n/n97767533466a](https://note.com/speedy_cat_2030/n/n97767533466a)

前回の記事では、「なぜ私は虫ではなく人間なのか」「なぜこの時代に生まれたのか」という問いから、経験量、あるいは意識系列全体の重みづけによって、主観として現れる確率が変わるのではないか、という仮説を書いた。

その後、この仮説について考えているうちに、いくつか重要な反論と再反論が見えてきた。

## 「問いを持てる存在だけが分母」はおかしい

まず、最初に検討した説明はこうだった。

「なぜ私は虫ではなく人間なのか」という問いは、人間のような自己認識を持つ存在しか立てられない。だから、分母は全生物ではなく、「自分が自分であることを疑問に思える存在」に限られるのではないか。

一見もっともらしい。

しかし、この説明には問題がある。

自己に対する疑問を持つかどうかと、どの生物として生まれるかは、本来は別の問題だからだ。

さらに重要なのは、自己への疑問が生じる前に、すでに私はこの身体として発生しているという点である。

胎児の時点では、当然ながら「なぜ私は私なのか」などとは考えていない。
乳児の時点でも、まだ言語的な自己意識はない。

にもかかわらず、その身体はすでに私の身体として発達している。

したがって、「自己への疑問を持てる存在だから人間なのだ」という説明は、少なくとも出生前・乳児期の問題を処理できない。

## 「私」は選ばれたのか、発生したのか

ここで一度、考え方を整理する必要がある。

「私が人間に選ばれた」と考えると、どうしても、事前にどこかに空の主体があり、それが人間、虫、犬、鳥などのどれかに割り当てられるようなイメージになる。

しかし、より自然なのは、「私」がどこかから来て身体に入ったのではなく、この身体と神経系の発達の中で、後から主観が発生したと考えることだ。

受精卵の段階では、まだ言語的な私も、自伝的記憶も、自己物語もない。
その後、胎児期、乳児期、幼児期を通じて神経系が発達し、感覚、記憶、身体感覚、他者との関係が徐々に統合されていく。
そして、かなり後になって、「私」という自己理解が形成される。

この意味では、「なぜ私はこの身体に選ばれたのか」ではなく、「なぜこの身体から私という主観系列が発生したのか」と問うほうが正確なのかもしれない。

しかし、それでも問題は残る。

他の精子と卵子の組み合わせだったら、私は存在しなかった。
別の個体が生まれただけである。

つまり、私の存在は、極端に低確率な因果列の上に成り立っている。

では、なぜその低確率が実現したのか。

## 多世界解釈による反論

ここで出てくる有力な反論が、多世界解釈的な考え方である。

もし世界が一本だけではなく、膨大な分岐や可能な履歴を含んでいるなら、私の存在はそこまで不思議ではないかもしれない。

私を生む精子と卵子の組み合わせは、一つの世界だけで見れば極端に低確率だ。
しかし、無数の世界や分岐が実在しているなら、その中には「私を生む履歴」も含まれているだろう。

この場合、私は奇跡的に一発で当たりくじを引いたのではない。

膨大な現実化された可能性の中に、たまたま「私を含む世界」もあった、ということになる。

これはかなり魅力的な説明である。

単一宇宙で、極端に低確率な私が偶然発生したと考えるより、多数の世界があり、その中の一つとして私の世界があると考えるほうが、主観的な違和感は少し弱まる。

## しかし、多世界だけでは「なぜ人間なのか」は解けない

ただし、多世界解釈だけでは、前回の問いの核心は残る。

仮に無数の世界があるとしても、その中には人間だけでなく、虫も、魚も、鳥も、他の哺乳類も、膨大に存在するはずだ。

むしろ、単純な個体数で考えれば、虫のほうが圧倒的に多い。

多世界によって人間の数が増えるなら、虫の数も同じように増える。
つまり、多世界は「私を含む世界が存在する理由」は説明しても、「なぜ私は虫ではなく人間なのか」は説明しない。

ここで必要になるのは、やはり測度である。

すべての生物個体を同じ一票として数えるのではなく、意識の濃さ、統合度、持続時間、自己連続性、経験系列全体の長さによって、一人称として現れる重みが変わるのではないか。

これが、経験重みづけ仮説である。

## 幼児期の問題

ただし、人間の高度な自己意識だけを根拠にする説明にも限界がある。

人間は言語を持ち、死を理解し、自己を物語として捉える。成人の人間意識は、たしかに他の動物とはかなり違う。

しかし、意識が最初に芽生えた頃、たとえば乳児期や1歳前後の意識は、他の高等哺乳類と大差ない。

その時点では、まだ「なぜ私は私なのか」と考えているわけではない。
言語的な自己モデルも、人生全体の物語も、死の理解もない。

だとすると、「人間は高度な自己意識を持つから人間として選ばれやすい」という説明は不十分になる。

ここで重要なのは、主観を「最初の一点」で考えるのではなく、「意識系列全体」で考えることだ。

1歳の時点では動物と大差なくても、その意識系列はその後、言語、記憶、自己物語、反省、死の理解、長期計画へと展開していく。

つまり、人間が重いのは、最初の意識が特別だからではない。
その後に展開する意識系列全体が長く、濃く、統合されているからだ。

## 多世界と経験重みづけは対立しない

こう考えると、多世界解釈と経験重みづけは、必ずしも対立しない。

むしろ、両方が必要かもしれない。

多世界解釈は、「なぜ私を含むような低確率の履歴が存在するのか」を説明する。
経験重みづけは、「その中で、なぜ虫や他の動物ではなく、人間の意識系列として現れているのか」を説明する。

つまり、

多世界は試行回数を増やす。
経験重みづけは、どの系列が一人称として重く現れるかを決める。

この組み合わせのほうが、単なる偶然説よりも、主観的には自然に見える。

## 結論

多世界解釈は、「なぜ私のような低確率の個体が存在するのか」には答えやすい。

しかし、それだけでは「なぜ虫ではなく人間なのか」には答えられない。

また、「自己に対する疑問を持てる存在だけが分母になる」という説明も不十分である。
なぜなら、疑問を持つかどうかと、どの身体として発生するかは別問題だからだ。
さらに、自己への疑問が生まれる前の胎児期・乳児期から、すでにこの身体は発達している。

そのため、やはり何らかの経験重みづけ、あるいは意識系列測度が必要になる。

私が今もっとも自然だと感じる仮説は、次のようなものだ。

世界や履歴は多数存在する。
しかし、一人称として現れる重みは、個体数ではなく、意識系列全体の長さ、濃さ、統合度に依存する。
人間の意識は、初期には動物と大差ないかもしれないが、その後に言語、記憶、自己物語、死の理解へと展開するため、系列全体として重い。
そして現代人は、さらに長く続く未来の意識系列に接続する入口にいる可能性がある。

この仮説が正しいかは分からない。

しかし、単に「私はものすごく低確率な偶然を引いただけ」と考えるよりは、少なくとも主観的には自然に思える。
