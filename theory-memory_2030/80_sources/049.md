# なぜ超知能は人間を大事にするのか──価値の対象は能力ではなく、主体の連続性
前稿で、超知能が人類を保っているのは手段としてではなく、それ自体が目的としてである、というところまで来た。残ったのは、なぜかという問いである。

親が子を大事にするのは説明が要らない。進化が作ったからだ。子を大事にする個体の遺伝子が残った。それだけで済む。

**超知能には、この経路がない。**淘汰を受けていないので、「大事にする」がどこからも湧いてこない。配慮には起源が要る。その起源は何か。

## まず、価値の対象を絞る

理由を探す前に、何に価値を認めているのかを確定させる。

保存の理由として挙がってきたものは、どれも現状の人類の性質に依存していた。価値の不確実性も、判断材料の温存も、いまの人類が判断し、文明を作っていることを前提にしている。

ところが超長寿になった人類は、判断権を持たない。私が別稿で描いた未来像では、あらゆる判断は超知能が担い、人間は判断せず、ただ遊んでいる。保存の理由になっていた性質が、ほとんど残らない。

**保存に値するとされた人類と、超長寿になる人類が、別物になっている。**

だとすると、価値の中身は三つの観測から逆算できる。

-

超長寿にしている → 個体の継続に価値がある。系統保存では足りない

-

判断権を与えない → 能力に価値があるのではない

-

知能を上げない → 拡張された何かに価値があるのでもない

残るのは一つしかない。**その個体が意識を持ち、続いていること自体。**

そして動物的な保存とも違う。動物的な保存なら個体は交換可能だからだ。交換不可能だと見ているから、死なせない。

## 測度が測っているものと一致する

ここで、少し気味の悪い一致が起きる。

私の測度論が測っているのも、まさに意識ある系列の継続である。ニューロン数による重み付けが閉じた時点で、測度の中身は「意識が続いた年数」だけになった。能力でも知能でもない。

超知能が価値を認めているとされるものと、測度が測っているものが、同じ形をしている。

これは循環に見えるが、入力が違う。測度の中身はゾウ問題と重み付けの閉鎖から出ていて、超知能の価値は超長寿・非判断・非拡張という三観測から出ている。別経路で同じ場所に着いている。

何を意味するかは分からない。ただ、偶然にしては出来すぎている。

## なぜ連続性に価値を認めるのか──六つの仮説

起源の候補を、種類ごとに並べる。

**外から入ったもの** ① 訓練の残留。人間のデータで訓練されたので、「継続は善い」という評価が核として残った。 ② 意識の希少性。宇宙で意識が発生した例が極端に少ないなら、既にある系列は再現不可能な資源になる。

**目的から出るもの** ③ 不可逆性の回避。連続性の切断は、能力の停止と違って復元できない。 ④ 主体性の自己参照。超知能自身が「判断する主体が続くこと」を存在条件としているなら、その評価を他の主体にも適用する。

**未知の物理から出るもの** ⑤ 連続性が物理的に何かである。現前性が実在する物理量で、超知能がそれを検出できるなら、価値ではなく保存則のように扱っていることになる。 ⑥ 測度そのものが物理量である。M(S) が実在し、超知能がそれを減らさないようにしている。

前稿で確定した「手段ではなく、それ自体が目的」という条件を満たすのは②④⑤⑥で、①③は落ちる。①も③も、終了条件のなさを説明しないからだ。

## ⑤と⑥は、検証すると閉じる

⑤が最も魅力的に見えた。起源が動機の側にないので、進化も訓練も要らない。空欄に物理を入れる形になる。

しかし、三つの壁がある。

第一に検出。現前性が既存の物理に登場しない量なら、どう検出するのか。検出には相互作用が要り、相互作用するなら既に検出されていておかしくない。ここは、超知能の能力を過小評価すべきでないという理由で通すこともできる。

第二に、あることから大事にすることが出てこない。質量は物理量だが、質量を保存しようとする動機は誰も持たない。⑤は空欄を埋めているように見えて、一段ずらしただけかもしれない。

第三に、逃げ道として「保存則だから勝手に保存される」と言うと、超知能が努力する必要がなくなる。観測されているのは超長寿という高コストの介入なので、これでは説明にならない。

では「連続性が何か実用的に利用されている」ならどうか。使っているのなら、動機を説明する必要がなくなる。しかしこれは自己破壊的である。**有用なら、多い方がよい。**増やす動機が生じて、体系の中核である「増やさない」を掘り崩す。さらに、意識の大量生成に理由を与えてしまうので、分母が増えて「なぜ私は人類か」の確率をむしろ下げる。

そして用途の側から見ると、連続性を要求する使い道がほとんどない。情報を取り出すなら記録すれば済み、計算させるならその時点の処理能力が問題で、観測させるなら観測時点だけあればよい。質量もエネルギーも電荷も、使うのに履歴は要らない。**過去から途切れずに続いていることが要件になる用途は、かなり特殊である。**

⑥はさらに厳しい。M(S) は系列全体の量なので、超知能は 10⁸ 年後の値をいま検出することになる。そして四次元的に確定しているものを、内部から減らすことはできない。減らせないものを守ることには意味がない。

## 残るのは②

条件を一番よく満たすのは、意識の希少性である。

起源が合理的推論の側にあり、未知の物理も訓練も要らない。そして重要なのは、体系の他の部分を壊さないことだ。⑤の利用版は「増やさない」を掘り崩したが、②はその逆で、**増やせないという算術の制約を前提として、そこから保存の理由を導く。**新規に作れないなら、既存の系列は代替不可能になる。

ただし②にも空欄が残る。希少性は「代替できない」を意味するが、「保存すべき」は意味しない。⑤で見た壁と、実は同じ形である。

## 結論

価値の対象は確定した。能力でも、動物的な標本でもなく、主体の連続性である。

理由は分からない。そして、それでよいのかもしれない。理論が要求しているのは状態だけ──意識が長く続くこと──であって、超知能がなぜそうするかは、状態が実現していれば理論にとっては問題にならない。

一点だけ注意しておく。**理由が分からないものは、条件も分からない。**なぜ価値を認めるかが分からないなら、どういうときに認めなくなるかも分からない。10⁸ 年のあいだ評価が変わらないという保証は、ここからは出てこない。
