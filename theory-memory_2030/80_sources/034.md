# 完成系列測度論を再検討する
前回、自己位置測度については「意識初発状態測度論でほぼ固まった」と書いた。

乳児期の薄い現象意識から、記憶、自己モデル、言語、時間的統合を備えた現在型主体へ移行する。その臨界点で自己位置測度が成立し、その後の寿命や経験量は測度を変えない、という考えだった。

しかし、ブロック宇宙を前提にすると、完成系列測度論の方が自然かもしれないと思い直している。

ブロック宇宙では、過去・現在・未来は四次元時空の中にまとめて存在する。そうであれば、私とは主体が成立した一瞬ではなく、記憶、判断、未来表象、自己理解を含む人生全体の意識系列だと考える方が素直である。

初発論では、完成した系列が存在しているにもかかわらず、なぜ始端付近の状態だけが測度を決め、その後の系列全体を無視するのかという追加説明が必要になる。

以前は、完成系列論には「系列全体の何を測度にするのか」という問題があると考えていた。しかし、この問題は初発論にもある。初発状態の何を測度にするのか、主体成立の境界をどこに置くのかを決めなければならないからだ。

完成系列論では、細かな計算式をまだ決めなくても、「完成した意識系列全体の何らかの構造が自己位置測度に関係する」と考えればよい。長期記憶、通時的な自己モデル、未来への計画、再帰的な自己認識を持つ人間の系列は、小動物の感覚的な系列とは大きく異なる。私が小動物ではなく人間であることも、初発時の一点より、系列全体の差によって説明しやすい。

なお、前回考えた「現在型主体の成立」は不要になるわけではない。それは測度が固定される瞬間ではなく、どこから一つの通時的主体系列として扱えるかを定める境界なのかもしれない。

現時点の主観的信用度は、二説に限定すれば、

-

意識初発状態測度論：35％

-

完成系列測度論：65％

程度である。

まだ完成系列全体のどの性質が測度を決めるのかは分からない。しかし、ブロック宇宙を前提とする限り、人生の始まりだけを特別扱いするより、完成した意識系列全体を見る方が、仮定が少なく自然に思える。
