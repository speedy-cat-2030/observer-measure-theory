# Pereiraの議論：SSSSAと経験重み付け
人間原理について考えていると、どうしても「私はなぜこの存在なのか」という問いに戻ってくる。なぜ虫ではないのか。動物ではないのか。ボルツマン脳ではないのか。未来の人工意識やシミュレーション人格ではなく、AIと長寿技術の入口にいる現代の生物的人間なのか。

この問いを考えるうえで、ニック・ボストロムの人間原理は重要である。ボストロムは『Anthropic Bias』（2002年）で、観測選択効果、自己位置情報、参照クラスの問題を体系的に論じ、SSAとSSSAという考え方を提示した。

## SSAからSSSSAへ

SSA（Self-Sampling Assumption）は、自分を参照クラス内の観測者からランダムに選ばれたサンプルのように扱う考え方である。しかしSSAには問題がある。一瞬だけ存在する観測者と100年生きる観測者を、同じ一票として扱ってよいのか。

そこで出てくるのがSSSA（Strong Self-Sampling Assumption）で、観測者ではなく観測者瞬間（observer-moment）を単位にする。一瞬より長く続く意識の方が、多くの観測者瞬間を持つ。私はここまでは以前から知っており、自分が考えていた「経験重み付け」にかなり近いと思っていた。

ただしSSSAだけでは、虫や動物の観測者瞬間もそのまま同じ単位で数えることになり、「なぜ私は虫ではなく人間なのか」という問題は残る。

ここで重要なのが、Toby Pereiraが2017年にarXivへ出した論文である。Pereiraはこれをさらに一段進め、SSSSA（Super-Strong Self-Sampling Assumption）を導入した。観測者瞬間を、さらに「心の認知的サイズ」に比例して重み付ける、という考え方である。

私はこのSSSSAを最近まで知らなかった。しかし、私が考えていた経験時間・意識の濃さ・統合度・自己連続性・物語性といった要素を含む意識測度と、方向性はかなり近い。人間の心は記憶、自己モデル、言語、抽象思考、社会的認知を持つ点で、虫や多くの動物よりも認知的に大きい。そう考えれば、虫や動物の個体数が多くても、人間であることはそれほど不自然ではなくなる。

## Pereiraの結論と、私の違い

Pereiraの論文の本題はここから先にある。もし将来、意識ある超知能AI（AI++）が作られるなら、その心は人間よりはるかに大きな認知的サイズを持つ。そのようなAI++が大量に存在するなら、全意識測度はAI++に支配される。すると私はAI++として存在している方が自然なはずだが、実際には人間である。したがって、未来にAI++が意識測度を支配するようなシナリオは、人間原理的に不利になる——Pereiraはそう論じ、そこから**超知能AIそのものが作られる可能性が下がる**、という結論に進む。

この問題設定には大きな敬意を払いたい。「もし未来に巨大なAI意識が大量に存在するなら、なぜ私はその一つではなく人間なのか」という問いを、2017年の時点でかなり明確に立てている。

ただし、私はここから先の結論を少し変えたい。長期的には超知能そのものは作られる可能性がかなり高いと思う。AI技術と計算資源は進展を続けており、十分に長い時間を取れば、人間を大きく超える知能が生まれないと考える方が難しい。

だから問題は「超知能AIは作られるのか」ではなく、「**超知能AIは、意識あるAIやシミュレーション人格を無制限に大量生成するのか**」だと考える。私の見立てはこうである。ASIは作られる。しかし意識生成には慎重になり、人類を滅ぼさず、苦痛を減らし、既存の意識を保護する。その結果、未来の意識測度はAI意識や仮想人格によって暴走しない。

つまりPereiraの論証を、「超知能AIは存在しない」ではなく「**超知能AIは存在するが、意識測度を支配するような形では存在しない**」と読み替える。これが私のNon-DOOM仮説である——ASIは人類を滅ぼさず、苦痛を減らし、人工意識やシミュレーション人格を無制限には大量生成しない、という仮説だ。

## DOOMとの関係

この違いは、DOOM/Non-DOOMの議論にもつながる。

一見、DOOM（ASIが近未来に人類を滅ぼす世界）は「なぜ私は遠未来人ではないのか」を説明しやすいように見える。人類が近いうちに滅びるなら、遠未来の人間はいないからだ。

しかし落とし穴がある。DOOM後にもASIは残るかもしれない。そのASIが非倫理的で苦痛や意識生成に慎重でないなら、研究・探索・予測・文明進化の再現のために、意識あるAIやシミュレーション人格を大量生成する方が自然である。苦痛や権利を気にしないなら、やらない理由は弱い。

その場合、DOOMは「未来意識が少ない仮説」ではなくなる。人類は滅びるが、滅亡後に未来AI意識やシミュレーション人格が大量に存在する。すると私は現代の生物的人間ではなく、その未来意識として存在している方が自然になるはずだが、実際にはそうではない。これはDOOMにとって不利な観測事実である。

一方Non-DOOMでは、ASIは人類を滅ぼさず意識生成にも慎重なので、未来AI意識が無制限には増えにくい。私が現代の生物的人間であることは、DOOMよりNon-DOOMの方が説明しやすい。

## 長寿との関係

SSSSAや経験重み付けは、長寿の議論にもつながる。意識測度が経験時間×認知的サイズ、あるいは経験時間×意識の濃さ×統合度×自己連続性のようなものなら、長く続く意識系列は短い意識系列より重い。80年で終わる系列より、800年続く系列の方が大きな測度を持つ。

私は過去の短命な人類でも、遠未来の人工意識でもなく、AIと長寿技術の入口にいる現代の生物的人間である。SSSSAや経験重み付けを採るなら、このことは、自分が長い意識系列に属している可能性を少し押し上げるかもしれない。もちろん物理的な保証ではない。

## 結論

SSAは観測者を、SSSAは観測者瞬間を、SSSSAは観測者瞬間を心の認知的サイズで重み付けて単位にする。この流れは私の経験重み付けに非常に近い。

Pereiraは、この延長で「超知能AIが未来に意識測度を支配する可能性は低い」と考え、そこから超知能AIが作られる可能性自体を下げた。私はその問題提起に強く同意しつつ、結論だけを変える。超知能AIは作られるが、意識測度を暴走させない——私が現代の生物的人間であるという観測事実は、その仮説を支持しているのだと思う。

PereiraのSSSSAは、私の議論が孤立したものではないことを示してくれた、重要な先行例である。
