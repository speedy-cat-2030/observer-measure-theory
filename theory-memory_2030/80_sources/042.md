# 初発論はなぜ落ちたか
自己位置測度理論の仮説は三つある。測度否定論、意識初発状態測度論、完成系列測度論。否定論については前回書いた。残る二つのうち、初発論について整理しておく。

初発論は、記事の半分以上で主役だった立場である。一度は「これでほぼ固まった」とまで書いた。それがなぜ落ちたのかを、順に記録しておく。

## 初発論とは

M(S) = φ(τ₀)。主体が成立した時点の値で測度が決まる、という立場だ。

乳児期の薄い現象意識から、記憶・自己モデル・言語・時間的統合を備えた現在型主体へ移行する。その臨界点で測度が確定し、**その後の寿命や経験量は測度を変えない**。

完成系列論との違いは一点だけである。初発論には**寿命の因子が入らない**。

## 理由1：読み取り点が、発達途上にある

これが最も強い。

初発論が読むのは、主体成立時点の φ である。人間の場合、3〜4歳あたりだ。

その時点の私に何があるか。語彙は数百から千程度、再帰的な構文はまだ不安定、記号操作はほぼゼロ。抽象化も、言語も、自己参照も、理論構築もない。

つまり初発論は、**発達途上の人間と、成熟したゾウやチンパンジーを比べる**ことになる。3歳児と成体のチンパンジーでは、物理的認知の課題で差がほとんど出ないという報告もある。

そして、人間が他の哺乳類に勝てる唯一の候補は、まさにその抽象化や言語だった。初発論は、自分が勝てる材料を読み取れない位置に立っている。

完成系列論やピーク型なら、成熟後の値が入るので使える。**初発論だけが落ちる。**

## 理由2：数字が動かない

実際に計算しても、初発論は問題を解かない。

φ をニューロン数の n 乗として計算すると、初発論は n=3 付近で頭打ちになり、2.3×10⁻⁴ を超えない。積分型は n=2 で 4.1×10⁻⁴。**どちらも 10⁻³ の壁を越えない。**

差は2倍程度しかない。理由は明快で、寿命の因子が効かないからである。人間70年に対してネズミ2年で35倍、ゾウ65年とはほぼ同じ。35倍という因子は、10⁷ の不足に対して誤差でしかない。

測度が断面か積分かは、この問いにほとんど影響しない。私は長いあいだそこを論じていたが、分母を哺乳類にして実際に計算すると、両者はほぼ同じ答えを出す。

## 理由3：非対称

そして、これが決め手になった。

ニューロン数による重み付けは、最終的に全部閉じた。総ニューロン数ではゾウが3倍で勝ち、皮質ニューロン数では人類が首位だが n=1 では 10⁻⁴ にしかならず、指数を上げる根拠はなく、相転移も置けない。同じ哺乳類で、同じ構造で、量が数倍違うだけの系に転移点を置く理由がないからだ。

この閉鎖は、両説に等しく効く。しかし**残ったものが違う**。

完成系列論には、寿命 L という自由変数が残った。L を十分に大きく取れば、観測は説明できる。

初発論には、何も残らなかった。寿命という変数を持たないので、閾値を置く以外に逃げ道がない。そしてその閾値は、同じ哺乳類のあいだには引けない。

**同じ一撃が、片方だけを殺している。**

## 初発論の側からの反論

公平のために書いておくと、逃げ道が一つある。

「言語能力そのもの」と「言語の実現」を分ければいい。3歳児は語彙が少ないが、言語を獲得する装置は既に持っている。装置の側で測るなら、成熟後と大きく変わらないかもしれない。

ただ、これは苦しいと思う。装置を持つことと、それが生む経験の量は別である。測度が経験に対応するなら、装置だけでは足りない。

そして「装置で測る」を認めると、新生児も装置を持っているので、主体成立の位置がかえって曖昧になる。

## 残ったもの

初発論が落ちて、残ったのは完成系列論である。

そして完成系列論を採ると、寿命が測度に直接効く。100万分の1を埋めるには、この系列が極端に長いことになる。

そこから先は、別の記事で書いた通りだ。
