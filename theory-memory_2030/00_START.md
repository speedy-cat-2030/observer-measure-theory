## 現行の最小モデル

**A/著者仮説**: 「なぜ私は過去の膨大な動物や未来の新規主体でなく現代起点の人間系列か」を自己位置測度で説明する。外部の抽選者/魂は不要。経験系列Sの測度を `M(S)=∫r(t)q(t)dt`、系列間の重みを `P(S)∝M(S)` と置く。r=経験時点数への時間変換、q=一時点のクオリア量。qの代理は皮質ニューロン数Nの1乗、魚は外套。時点間だけでなく同時点内の分離したクオリアも足すという論拠。実証済みの物理法則ではない。

参照資格は質問能力でなく意識の成立。神経相同性から哺乳類を保守的基準、魚類までを現行の基本分母とする。過去の人間測度比は哺乳類で `5e-4`、魚類込みで `2e-6`。全脳N/無重み/高い指数の古い試算を混ぜない。

未来は(a)短く終わる、(b)新規主体の出生を止め既存コホートが長く続く、の比較。(b)なら既存系列の未来経験が分子に入り、過去の人間の希少性を軽減しながら未来出生者の大分母を作らずに済む。**系列内部の時点は順次通過し再抽選しない**という条項が必須。「今この瞬間」を無作為抽出すると(b)の利益はほぼ消える。系列境界は未解決。SIAでは出生順位の議論が相殺され、(b)推論はSSA側の選択に依存する。

モデルは現在コホート `1e10人`。著者表のP=.5到達は哺乳類約100万年、魚類約6.8億年(s=1)。丸め定数から再計算した魚類値は約6.83億年。個人の不死/寿命保証ではない。動物側フローが地球生物圏の有限寿命で止まるなら、既存人類が無期限に続き新競合もない条件でP→1。凍結するのは動物ストックで総分母ではない。

低い目が出ただけという立場は矛盾なく残る。現行の例示尤度比は `.5/(2e-6)=2.5e5`。事後確率には(b)事前が必要で未決。大きい尤度比だけで未来を確定しない。
