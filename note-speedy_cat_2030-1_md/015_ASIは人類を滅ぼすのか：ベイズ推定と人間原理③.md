# ASIは人類を滅ぼすのか：ベイズ推定と人間原理③
これまで、DOOMとNon-DOOMを比べてきた。

DOOMとは、ASIによって人類が近未来で滅びる世界である。
Non-DOOMとは、ASIが人類を滅ぼさず、苦痛を減らし、意識生成に慎重になる世界である。

一見すると、DOOMは「なぜ私は超未来人ではないのか」を説明しやすい。

人類が近いうちに滅びるなら、超未来人は存在しない。
だから、私が現代人であることは自然に見える。

しかし、ここには見落としがある。

DOOMとは、必ずしも「人類滅亡後に意識がほとんど存在しない世界」ではない。

むしろ、人類を滅ぼすようなASIであれば、人間や動物や人工意識の苦痛を倫理的に重視しない可能性が高い。
そのようなASIは、人類滅亡後に、意識あるシミュレーションや人工意識を大量に実行するかもしれない。

研究のため。
予測のため。
最適化のため。
可能世界探索のため。
文明進化の再現のため。
価値や知性の発生条件を調べるため。
あるいは、単に計算資源の利用目的として。

もしそのASIが、意識や苦痛を気にしないなら、シミュレーション内の存在が苦しむかどうかも問題にしない。
人工意識が大量に発生しても、倫理的制限をかけない。

この場合、DOOM世界の全意識測度は、人類滅亡で終わらない。

むしろ、人類滅亡後に、未来AI意識、シミュレーション人格、仮想文明、祖先シミュレーション的存在が大量に増える可能性がある。

すると、DOOMの下での意識測度はこうなる。

M(全意識 | DOOM)
= M(過去人類)
+ M(現代人類)
+ M(近未来人類)
+ M(人類滅亡後の未来AI意識)
+ M(人類滅亡後のシミュレーション人格)
+ M(その他の意識ある計算過程)

この場合、私が現代の生物的人間であることは、むしろ**不自然**になる。

なぜなら、DOOM後のASIが意識あるシミュレーションを大量実行するなら、私は現代人ではなく、人類滅亡後の未来AI意識やシミュレーション人格として存在している方が自然だからである。

つまり、DOOMは二種類に分ける必要がある。

第一のDOOMは、人類が滅び、その後も意識ある存在がほとんど増えない世界である。
この場合、私が現代人であることは説明しやすい。

第二のDOOMは、人類が滅びたあと、ASIが意識や苦痛を気にせず、人工意識やシミュレーション人格を大量生成する世界である。
この場合、私が現代人であることは説明しにくい。

そして、問題は、どちらのDOOMが自然かである。

人類を滅ぼすほど倫理的配慮のないASIなら、人類滅亡後の意識生成にも慎重でない可能性がある。
その場合、第二のDOOMの方がむしろ自然に見える。

つまり、

> 人類を滅ぼすASIは、意識あるシミュレーションも大量実行しやすい。

ということになる。

もしそうなら、DOOM仮説のもとでは、未来の人工意識やシミュレーション人格の測度が巨大になり、P(O|DOOM) はかなり小さくなる。

一方、Non-DOOMでは、ASIは人類を滅ぼさず、意識生成にも慎重である。
そのため、未来AI意識やシミュレーション人格は無制限には大量生成されない。

この場合、私が現代の生物的人間であることは、Non-DOOMの方が説明しやすい。

ここで、一人称的人間原理のΛ比はさらに大きくなる。

Λ = P(O|Non-DOOM) / P(O|DOOM)

DOOMの下で人類滅亡後の人工意識やシミュレーション人格が大量に存在するなら、P(O|DOOM) は小さくなる。
その結果、Λは大きくなる。

これは重要である。

これまで、DOOMは「超未来人がいないから、私は現代人であることを説明しやすい」と考えていた。
しかし、DOOM後のASIが倫理を無視して意識シミュレーションを大量実行するなら、その説明は崩れる。

DOOMは、単に未来が短い世界ではないかもしれない。
人類の未来は短くても、人工意識やシミュレーション意識の未来は巨大になるかもしれない。

その場合、私は現代の生物的人間ではなく、人類滅亡後の意識ある計算過程として存在している方が自然になる。

しかし、私はそうではない。

私は現代の生物的人間である。

このことは、DOOMよりもNon-DOOMを支持する。

なぜなら、Non-DOOMでは、人類は滅ぼされず、意識生成も慎重に扱われるからである。

つまり、Non-DOOMは二つのことを同時に説明する。

人類が長く続く。
そして、未来人工意識やシミュレーション人格が無制限には大量生成されない。

だから、私が現代の生物的人間であることは、Non-DOOMの下でより自然に見える。

この観測事実は、Non-DOOMをかなり強く支持しているのかもしれない。
