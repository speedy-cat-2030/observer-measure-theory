# ASIは人類を滅ぼすのか：ベイズ推定と人間原理①
## ASIによるDOOMと、一人称的人間原理

三人称的にASIを見ると、人類はかなり危うい。

ASIは人間より圧倒的に強い。
人間の価値観と一致する保証はない。
人類は資源を使い、予測不能で、将来のリスクにもなる。

単純に能力と目的不一致だけを見るなら、DOOM、つまり人類滅亡の方向に見える。

しかし、一人称的人間原理から見ると、別の方向の更新が起きる。

私は虫ではなく人間である。
私はボルツマン脳ではなく、連続した人生を持つ人間である。
私は超未来の人工意識ではなく、AIと長寿技術の入口にいる現代人である。
私はさらに内側の祖先シミュレーション存在ではなく、この階層にいるように見える。

この観測事実をどう扱うべきか。

ここでは、DOOM と Non-DOOM を比べる。

DOOM：

> ASIによって人類は近未来で滅びる。

Non-DOOM：

> ASIは人類を滅ぼさず、苦痛を減らし、意識生成に慎重になる。

ここでいう Non-DOOM は、単に「人類がたまたま生き残る」という意味ではない。

人類由来の意識系列が長く続く。
ASIは人類を滅ぼさない。
苦痛は減らされる。
人工意識やシミュレーション人格は無制限には大量生成されない。

そういう仮説である。

そして、観測事実 O を置く。

> O：私は現代の生物的人間として存在している。

考えるべきなのは、次の二つである。

P(O|DOOM)

P(O|Non-DOOM)

つまり、

> DOOMが正しいとして、私が現代の生物的人間であることはどれくらい自然か。

そして、

> Non-DOOMが正しいとして、私が現代の生物的人間であることはどれくらい自然か。

という比較である。

ベイズ的には、次の形になる。

P(Non-DOOM|O) / P(DOOM|O)
= P(Non-DOOM) / P(DOOM) × P(O|Non-DOOM) / P(O|DOOM)

つまり、Non-DOOM が DOOM に対してどれくらい有利になるかは、

事前オッズ × 尤度比

で決まる。

三人称的ASI分析は、主に P(DOOM) を高くする。
一人称的人間原理は、主に P(O|Non-DOOM) を高くする。

だから問題は、

> P(O|Non-DOOM) / P(O|DOOM) がどれくらい大きいか

である。

## 観測事実 O の中身

「私は現代の生物的人間である」という観測事実 O は、いくつかに分解できる。

O1：私は虫ではなく人間である。
O2：私はボルツマン脳ではなく、連続した人生を持つ人間である。
O3：私はAIと長寿技術の入口にいる現代人である。
O4：私は超未来の人工意識・AI人格・仮想人格ではない。
O5：私はさらに内側の祖先シミュレーション存在ではない。

つまり、

O = O1 かつ O2 かつ O3 かつ O4 かつ O5

である。

ただし、これらは独立ではない。
だから単純に全部を掛け算するのは危険である。

しかし、それぞれの観測が DOOM と Non-DOOM のどちらを支持しやすいかは考えられる。

## 意識測度 M で考える

ここで、単なる人数ではなく「意識測度」で考える。

M(〇〇) は、

> 〇〇に属する意識経験の総量

を表す記号である。

たとえば M(現代人類) は、現代人の人数そのものではない。

人数、経験時間、意識の濃さ、統合度、自己連続性、記憶や物語性などを含めた、現代人類全体の意識経験の重みである。

かなり単純化すれば、

M(ある存在の集団) = 個体数 × 経験時間 × 意識の濃さ × 統合度 × 自己連続性

のようなものとして考えられる。

もちろん、これは厳密に測定できる物理量ではない。
あくまで、一人称的人間原理を考えるための概念的な記号である。

このとき、

P(O|DOOM) = M(O|DOOM) / M(全意識|DOOM)

P(O|Non-DOOM) = M(O|Non-DOOM) / M(全意識|Non-DOOM)

と考える。

つまり、その仮説の下に存在する全意識測度のうち、Oに該当する意識測度がどれくらいの割合を占めるかを見る。

## DOOMの場合

DOOMでは、人類は近未来で滅びる。

この場合、未来の長寿人類や大量の人工意識はほとんど存在しない。

大まかには、

M(全意識 | DOOM)
= M(過去人類)
+ M(現代人類)
+ M(近未来人類)
+ M(人間以外の動物)
+ M(虫などの小さな神経系を持つ生物)
+ M(ボルツマン脳)

となる。

DOOMでは、M(長寿未来人類)、M(未来AI意識)、M(シミュレーション人格) は、ほぼゼロに近い。

だから、私が超未来人や未来人工意識ではないことは説明しやすい。

そもそも、そのような存在がほとんどいないからである。

DOOMはこう説明する。

> 私が現代人なのは、人類が近いうちに終わり、超未来人がほとんど存在しないからである。

これはかなり強い説明である。

特に、

> なぜ私は超未来ではないのか。

という問いに対して、DOOMは単純な答えを持つ。

> 超未来がないから。

ただし、DOOMには弱点もある。

なぜ私は虫ではなく人間なのか。
なぜ私はボルツマン脳ではなく、連続した人生を持つ人間なのか。
なぜ私はAIと長寿技術の入口にいる現代人なのか。

これらは、DOOM単体からはあまり自然には出てこない。

## Non-DOOMの場合

Non-DOOMでは、ASIは人類を滅ぼさない。

人類は保存される。
苦痛は減らされる。
長寿化が進む。
人工意識やシミュレーション人格は無制限には大量生成されない。

この場合、

M(全意識 | Non-DOOM)
= M(過去人類)
+ M(現代人類)
+ M(長寿未来人類)
+ M(人間以外の動物)
+ M(制限された未来AI意識)
+ M(制限されたシミュレーション人格)

となる。

DOOMとの大きな違いは、M(長寿未来人類) が入ってくることである。

つまり、人類由来の意識系列が未来まで長く続く。

ただし、Non-DOOMでは、未来AI意識やシミュレーション人格が無制限に増えるわけではない。

もし未来AI意識やシミュレーション人格が天文学的に大量生成されるなら、M(未来AI意識) や M(シミュレーション人格) は M(現代人類) より圧倒的に大きくなる。

その場合、私は現代の生物的人間ではなく、未来AI意識やシミュレーション人格として存在している方が自然になる。

しかし、私は現代の生物的人間である。

したがって、Non-DOOM がこの観測事実と整合するためには、未来AI意識やシミュレーション人格は、存在するとしても無制限には大量生成されない必要がある。

## なぜ現代人なのか

Non-DOOMには一見、問題がある。

未来に長寿人類が大量に存在するなら、なぜ私は未来人ではなく現代人なのか。

単純には、

P(現代人 | Non-DOOM) = M(現代人類) / M(全意識 | Non-DOOM)

である。

M(長寿未来人類) が大きくなるほど、この値は小さくなる。

つまり、Non-DOOMは人類存続を説明する代わりに、

> なぜ私は長寿未来人ではなく、現代人なのか。

という問題を抱える。

ここで重要なのが、「現代人を単独の短命個体としてではなく、未来へ接続する意識系列の入口として見る」という考え方である。

通常なら、現代人の人生は80年から100年程度で終わる。

しかし、現代人の一部が、長寿技術やASIによって未来へ接続するなら話は変わる。

その場合、現代人は単なる短命な現代個体ではなく、長寿未来へ続く意識系列の開始点になる。

つまり、M(現代人類) を単なる「現代だけの人間の測度」として見るのではなく、M(現代起点の長寿人類) として見る余地がある。

現代は、AIと長寿技術の入口にある。

過去は短命だった。
未来は長寿化しているかもしれない。
そして現代人は、その境界にいる。

この場合、Non-DOOMはこう説明する。

> 私が現代人なのは、現代が長く続く意識系列の入口だからである。

## DOOMとNon-DOOMの違い

同じ観測事実、

> 私は現代人である。

を、DOOMとNon-DOOMはまったく違う形で説明する。

DOOMではこうなる。

現代人である
→ 人類が近いうちに終わるため、超未来人がいない
→ 現代は終わりに近い時代である

Non-DOOMではこうなる。

現代人である
→ AIと長寿技術の入口にいる
→ 現代は長寿未来への入口である

この二つは、正反対の解釈である。

DOOMは、現代を終末前夜として見る。
Non-DOOMは、現代を長寿未来の入口として見る。

どちらも、私が現代人であることを説明できる。

だから、現代人であることだけでは決着しない。

必要なのは、O全体を見ることである。

## 尤度比で見る

全体として、見るべきなのは次の比である。

Λ = P(O|Non-DOOM) / P(O|DOOM)

これが1より大きければ、観測事実OはNon-DOOMを支持する。

Λ > 1

なら、一人称的人間原理はNon-DOOM方向への更新を与える。

逆に、

Λ < 1

なら、OはDOOMを支持する。

私の直感では、O全体を考えると、

Λ > 1

だと思う。

私は虫ではなく人間である。
私はボルツマン脳ではなく、連続した人生を持つ。
私はAIと長寿技術の入口にいる。
私は未来人工意識ではない。
私はさらに内側のシミュレーション存在ではない。

これらをまとめると、

> 私は、長く続く可能性を持つ生物的人間意識系列の入口にいる。

というNon-DOOM側の説明は、それなりに統一的である。

ただし、問題はその強さである。

Λ = 2 程度なのか。
Λ = 10 程度なのか。
Λ = 1,000,000 のように圧倒的なのか。

ここは分からない。

最終的な事後オッズは、

P(Non-DOOM|O) / P(DOOM|O) = P(Non-DOOM) / P(DOOM) × Λ

で決まる。

仮に三人称的ASI分析によって、事前オッズが強くDOOM寄りだとする。

たとえば、

P(Non-DOOM) / P(DOOM) = 1 / 100

だとする。

このとき、Non-DOOMがDOOMを上回るには、

Λ > 100

が必要になる。

つまり、一人称的人間原理による尤度比が100倍以上でなければ、DOOMを逆転できない。

もし Λ = 10 なら、Non-DOOM方向には更新されるが、まだDOOMが残る。

逆に、もし Λ = 1,000 なら、Non-DOOMがかなり有利になる。

したがって、本当の問いは、

> P(O|Non-DOOM) は P(O|DOOM) よりどれくらい大きいのか。

である。
