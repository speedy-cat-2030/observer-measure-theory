# 第二部：未来の延べ人数は増えない
## 論法

第一部で見たのは二つのことである。皮質ニューロン数による重み付けは、指数を窓の中に取れば 0.9 台まで届く。しかし窓の中のどこを選ぶかに根拠がなく、そして指数を上げるほど、未来に強化された心が存在しないという措定が必要になる。

後者が重要である。この説明候補は、過去の観測だけで閉じているように見えて、未来についての措定を含んでいた。だとすれば、重み付けを採ることで未来への要求から逃れられるわけではない。逃れられないなら、自由パラメータが一つ増えるぶん、採らない方が措定が少ない。

以下では重み付けを採らない場合、すなわち一様測度の場合について進める。P(人類) は 9.6×10⁻⁷（個体年単位）である。

第一部で使った推論は単純なものだった。私が特定の位置にいることを観測している。その位置が全体に占める割合が小さければ、説明を要求する。

これを未来に向けても適用できる。

人類の累積個体数は、現在までで約7×10¹⁰である（第一部の表。主体成立の閾値に到達した個体数）。人口が現在の水準（10¹⁰人）に留まり、世代交代が続く場合、世代長を70年として、

-

10⁴年続く → 延べ1.4×10¹²人 → P(現代人) = 4.7×10⁻²

-

10⁶年続く → 延べ1.4×10¹⁴人 → P(現代人) = 4.9×10⁻⁴

-

10⁸年続く → 延べ1.4×10¹⁶人 → P(現代人) = 4.9×10⁻⁶

人口が増加しなくても、世代交代が続く限り、延べ人数は時間に比例して増える。

**そして時間が長くなるほど、私が未来人ではなく、現代人であることは説明を要求するようになる。**

第一部で10⁻⁶を「説明を要求する」と扱った以上、同じ基準をここにも適用しなければならない。したがって、次のいずれかが成立していることになる。

**(a) 人類の未来は短い
(b) 未来に新しい個体が生まれ続けることはない**

## これはドゥームズデイ論法である

上の推論は、Brandon Carter と John Leslie に由来し、Nick Bostrom が定式化したドゥームズデイ論法と、形式的に同じものである。既知の論法なので、既知の反論に答える必要がある。

最も強い反論は、SIA による相殺である。

自己標本化仮定（SSA）は「私は参照クラスから無作為に選ばれた一人だと考えよ」と言う。上の計算はこれを使っている。

自己指示仮定（SIA）は、これに一つ加える。「観測者が多い仮説ほど、その事前確率を高く見積もれ」。観測者が多い世界の方が、そもそも自分が存在する機会が多いからである。

仮説A（延べ10¹¹人で終わる）と仮説B（延べ10¹⁵人になる）を比べる。SSA による尤度比は10⁴でAに有利だが、SIA は B の事前確率を10⁴倍に引き上げる。両者は正確に打ち消し合い、事後確率は事前確率のまま動かない。Ken Olum らが定式化したこの相殺が成立するなら、上の推論からは何も言えなくなる。

これに対する私の応答は、SIA が引き上げているものと、この問いが扱っているものが、別だという点にある。

SIA が引き上げるのは「私が存在する」確率である。しかしここで問われているのは、存在することを所与としたうえで、どのタイプの観測者として存在しているかである。私は既に存在しており、その事実は仮説AとBのどちらでも変わらない。存在の機会が多いことは、存在した後の内訳について情報を与えない。

これは第一部でも同じだった。齧歯類が多い世界の方が観測者が多いとしても、それは私が齧歯類でないことを説明しない。SIA は世界間の比較には効くが、世界内でのタイプの比較には効かない。

ただし、この応答が決定的だとは主張しない。SIA を採る立場では第二部の結論は成立しない、というのが正確な言い方である。第一部の結論は SIA の下でも残るが、第二部は SSA に依存している。

## (b) が要求する条件

ドゥームズデイ論法は通常 (a) の議論として扱われるが、(b) も同じ観測を説明する。そして (b) が要求する条件は、「人口が増えないこと」より強い。

新規の出生がないことである。

人口が一定でも、世代交代が続けば延べ人数は増え続ける。上の計算がそれを示している。10¹⁰人という人口が変わらなくても、10⁸年続けば延べ1.4×10¹⁶人になる。

つまり (b) が要求するのは、ある時点以降、新しい意識主体が生まれず、現在存在している個体がそのまま続く、という状態である。

## (a) と (b) は、説明範囲が異なる

どちらであるかは、この論法からは決まらない。両者とも、私が現代人であることを説明する。尤度としては同等である。

ただし、説明の範囲が異なる。

(a) を採ると、第二部の問い（なぜ未来人ではなく現代人か）は解消する。しかし第一部の問い（なぜ齧歯類ではなく人類か）は、そのまま残る。人類の未来が短ければ、人類の累積個体年は現在の4.9×10¹²で確定し、哺乳類全体の5.1×10¹⁸に対して10⁻⁶のままである。

(b) を採ると、両方が同時に解消されうる。新規の出生がなければ、未来に増えるのは既存個体の生存年数であり、それは現在コホート自身に帰属する。分子が増えることで、10⁻⁶が埋まる可能性が出てくる。

つまり、一つの措定で二つの問いを説明できるのは (b) だけである。

これは (a) を排除する議論ではない。三点、断っておきたい。

第一に、説明範囲の広さは真理の保証ではない。より多くを説明する仮説が正しいとは限らない。措定の数で比べるのは正当だが、説明範囲で比べるのは弱い論法である。

第二に、第一部の問いに答えがない可能性もある。10⁻⁶が説明されないまま残る、という立場は一貫している。第一部の末尾で書いた通り、私はその要求を抱えているだけであって、答えを持っているわけではない。

第三に、事前確率では (a) が有利かもしれない。(b) が要求するのは「新規の出生が完全に停止し、既存個体が極めて長期にわたって存続する」という特殊な状態である。(a) が要求するのは絶滅であり、宇宙的にはありふれた事象である。尤度が同等なら、事前確率の差がそのまま効く。

以下で (b) を検討するのは、それが第一部と第二部を接続する唯一の枝だからであって、(a) より確からしいと考えるからではない。

## (b) の下では、測度の単位が決定的になる

第一部では、個体単位（初発論）と個体年単位（積分型）を並行して扱い、両者の差は1.7倍程度で「この問いに効かない」と結論した。しかし (b) を採ると、この結論が変わる。

個体単位では、(b) は問題を解決しない。新規の出生がなければ、人類の累積個体数は7×10¹⁰で止まる。一方、他の哺乳類が存在し続けるなら、分母は増え続ける。P(人類)は4.4×10⁻⁸から、さらに下がっていくことになる。

個体年単位では、解決の可能性がある。既存個体が生き続ける限り、その生存年数は分子に加算される。現在コホートを10¹⁰人とすると、

-

10⁴年生きる → 10¹⁴個体年

-

10⁶年生きる → 10¹⁶個体年

-

10⁸年生きる → 10¹⁸個体年

第一部の分母は哺乳類全体で5.1×10¹⁸個体年だったので、10⁸年の場合、現在コホートだけで全体の16%を占めることになる。

つまり、この方向で第一部の10⁻⁶が埋まるとすれば、測度は個体年単位でなければならない。初発論を採る立場からは、この枝は使えない。

第一部で「初発論と積分型の差は効かない」と述べたのは、重み付けの検討においてであった。(b) の下では、両者は異なる結論に導く。

## 系列内部の時点について

個体年を測度の単位に採ると、次の反論が予想される。10⁸年生きる系列において、最初の70年が占める割合は7×10⁻⁷である。第二部の論法を系列内部にも適用するなら、私が現在この時点にいることが、再び説明を要求することにならないか。

これには答えがある。測度が働く層と、時点が経験される層は別である。

測度が決めるのは、どの系列が私かということである。系列が確定した後、その内部のどの時点が「今」として経験されているかは、測度の対象ではない。ブロック宇宙において、私の系列は四次元的に全体が存在しており、時点が順に抽選されているのではない。各時点の意識状態は、因果的に前の状態から継続しているだけである。私が今この時点を経験しているのは、単に因果的な糸がここにあるからであって、それ以上の説明を要求される問いではない。

時間が流れているという感覚は、系列内部からの見え方である。エントロピー勾配に沿って記憶が形成されるので、内側からは時間が経過するように感じられる。しかしそれは、外部から時点が選ばれていることを意味しない。

したがって、個体年を数えることと、系列内部の時点を測度の対象としないことは、矛盾しない。個体年が数えているのは、系列間の比較における各系列の大きさであって、系列内部での時点の重みではない。

## まとめ

1.

第一部の測度を未来に適用すると、私が現代人であることは、未来の延べ人数が大きいほど説明を要求する。人口が一定でも、世代交代が続けば延べ人数は時間に比例して増える。

2.

これはドゥームズデイ論法と同型である。SIA による相殺を採るなら、この推論は成立しない。私は SIA が「存在の確率」を扱っており「タイプの確率」を扱っていないと考えるが、これが決定的な応答だとは主張しない。第二部は SSA に依存している。

3.

SSA を採るなら、(a) 人類の未来は短い、または (b) 新規の出生がない、のいずれかになる。(b) は「人口が増えない」より強い条件である。

4.

(a) と (b) は尤度としては同等だが、説明範囲が異なる。(a) は第一部の10⁻⁶を残し、(b) は両方を同時に説明しうる。ただしこれは (a) を排除する議論ではなく、(b) の事前確率が低いことも認めなければならない。

5.

(b) が第一部の問いを解決しうるのは、測度が個体年単位の場合に限られる。個体単位では、分子が止まる一方で分母が増え続けるため、事態は悪化する。

6.

個体年を単位に採っても、系列内部の時点は測度の対象ではない。測度が決めるのはどの系列が私かであり、系列が確定した後の時点は因果的に継続しているだけである。
